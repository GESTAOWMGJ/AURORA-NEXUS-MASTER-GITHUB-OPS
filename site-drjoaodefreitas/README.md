# Site institucional — drjoaodefreitas.com.br

Fundação estática para publicação na Vercel.

## Estado

- Site institucional responsivo: pronto.
- Coleta de dados: desativada.
- Analytics/pixel: não instalado.
- Agenda e triagem: aguardando ambientes seguros.
- E-mails: aguardando Google Workspace.
- Identidade visual definitiva: aguarda importação dos ativos originais do timbrado/folder.

## Deploy

1. Conectar o repositório `GESTAOWMGJ/automacao-gestao-wmgj` à Vercel.
2. Definir `site-drjoaodefreitas` como Root Directory.
3. Publicar a URL de homologação.
4. Adicionar `drjoaodefreitas.com.br` e `www.drjoaodefreitas.com.br`.
5. Copiar para o Registro.br apenas os registros DNS exibidos pela Vercel.
6. Validar HTTPS, redirecionamento e cabeçalhos de segurança.

## Regra de dados

Nenhum formulário clínico deve ser adicionado diretamente ao site estático. Triagem e agenda devem operar em endpoints próprios, com consentimento, autenticação quando necessária, segregação por tenant e política de retenção.
